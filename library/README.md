# Library

This directory contains the first system in the benchmark.

## Subdirectories

- `provengo/` — the Provengo model and test specification
- `sut/` — the system implementation or mock SUT used for validation
- `reference/` — OpenAPI and ground-truth artifacts used as references
- `notes/` — research notes and working analysis
- `scripts/` — helper scripts for running experiments
